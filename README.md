# 🔊 Payment Sound Box Prank

A fun **simulated payment sound-box prank website** built with HTML, CSS and JavaScript.

Enter any amount and the browser plays a sound-box style **“Payment Received”** announcement. 🎉

> ⚠️ **Disclaimer:** This is only a fun demo/prank. No real payment, transaction, UPI verification, or money transfer takes place.

## ✨ Features

* 💰 Enter any amount
* 🔊 Payment received voice announcement
* 📱 Mobile-friendly design
* 🎨 Modern and responsive UI
* ⚡ No backend required
* 🌐 Works directly in a web browser
* 🛡️ No real payment processing

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Browser Text-to-Speech API

## 🚀 Run Locally

1. Download or clone this repository.
2. Open `index.html`.
3. Enter an amount.
4. Click **Simulate Payment**.
5. Listen to the sound-box announcement. 🔊
